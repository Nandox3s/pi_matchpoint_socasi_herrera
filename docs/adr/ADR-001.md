# ADR-001: Android nativo, MVVM y backend de servicios

- Estado: aceptado
- Fecha: 2026-08-12

## Contexto

Los Must son autenticación, perfil, consulta, reserva sin cruces y administración por rol. Torneos avanzados son Should. MoSCoW prioriza primero el recorrido que valida valor y seguridad.

## Decisión

Kotlin + Compose con MVVM/Repository; Retrofit; StateFlow; Cognito; Spring Boot/PostgreSQL tras Nginx. El App Client móvil es público y no incorpora client secret.

## Razones y consecuencias

- Compose aporta componentes y diseño consistente.
- MVVM permite pruebas y evita acoplar HTTP a UI.
- Repository desacopla Cognito/HTTP y centraliza errores.
- El backend sigue siendo autoridad de negocio.
- Coste: mantener DTOs y configuración externa de Cognito.
- Riesgo: SharedPreferences no cifra adicionalmente; producción debe respaldar el refresh token con Android Keystore.

## Alternativas descartadas

- Retrofit desde Composables: acoplamiento y pruebas difíciles.
- Client secret dentro del APK: es extraíble.
- Base local principal: no resuelve concurrencia multiusuario.
