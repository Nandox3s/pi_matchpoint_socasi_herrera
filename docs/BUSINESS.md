# Modelo de negocio

## Business Model Canvas

| Bloque | MatchPoint |
|---|---|
| Segmentos | jugadores, organizadores y administradores de canchas |
| Propuesta | reservar sin llamadas/cruces; ocupar horas libres; operar torneos en un lugar |
| Canales | Android, complejos, redes y ligas universitarias |
| Relación | autoservicio, soporte y onboarding de managers |
| Ingresos | comisión por reserva, plan mensual y tarifa por torneo |
| Recursos | plataforma, API, disponibilidad, marca y acuerdos |
| Actividades | desarrollo, nube, adquisición, soporte y analítica |
| Socios | complejos, universidades, pagos y proveedor cloud |
| Costes | nube, soporte, ventas, marketing, pagos y mantenimiento |

La disponibilidad unificada y el control transaccional reducen dobles reservas. El mismo inventario alimenta reservas y torneos, convirtiendo horas ociosas en ingresos.
